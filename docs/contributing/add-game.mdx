---
title: Adding a New Game
sidebar_position: 2
---

To add support for a new game:

1. Add an entry to `configs/game_info.yml`, following the structure in [Configuration Files](./configuration-files.mdx).
2. Test the installation using the [Docker test environment](./testing.mdx) or a local setup.
3. If the game needs special steps or known workarounds, add a game guide under `docs/game-guide/` and link it from the [Game Guides index](../game-guide/index.mdx).
4. Follow the [Pull Request Guidelines](./pull-request.mdx) when submitting your change.
