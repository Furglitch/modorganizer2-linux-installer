## Themes

MO2-LINT can apply a Mod Organizer theme to new instances, selected in the TUI or with the `--theme` CLI flag. A default theme can be set in [Configuration].

### Included with Mod Organizer

These themes ship with Mod Organizer 2 itself, so nothing extra is downloaded.
