MO2-LINT accepts a variety of commands and options for creating and managing instances.

:::tip
Prefer an interactive interface? Run `mo2-lint` with no command to open the TUI. See the [TUI Guide] for more information.
:::

## Commands

| Command | Purpose | Info |
|:--|:--|:--|
| `install` | Create a new MO2 instance for a game. | [Go to Reference](./command-reference.mdx#install) |
| `update` | Update an existing instance's MO2 build and refresh its launch configuration. | [Go to Reference](./command-reference.mdx#update) |
| `uninstall` | Remove an existing MO2 instance. | [Go to Reference](./command-reference.mdx#uninstall) |
| `pin`/`unpin` | Pin an existing MO2 instance's versions and configuration. | [Go to Reference](./command-reference.mdx#pin-and-unpin) |
| `list` | List existing instances. | [Go to Reference](./command-reference.mdx#list) |

:::note
Read the [Game Guides] before creating an instance. Some games need extra steps.
:::
