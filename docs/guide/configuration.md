# Configuration

MO2-LINT keeps its user data in two files within `~/.config/mo2-lint/`: a user-editable settings file (`settings.toml`) and an automatically managed instance state file (`state.json`). Both are created on first run.

## The settings file: `settings.toml`

Located at `~/.config/mo2-lint/settings.toml`.

### `[installer]`

| Key | Description |
|:--|:--|
| `log_level` | Default log level when `--log-level` isn't provided. `INFO` if unset. |
| `check_updates` | Set `false` to skip the startup GitHub version check. |
| `refresh_configs` | Set `false` to skip pulling remote config files on startup. |

### `[instance]`

| Key | Description |
|:--|:--|
| `launcher` | Default launcher when one isn't provided with `--launcher`. Leave blank to auto-detect. If the selected game isn't available on the selected launcher, MO2-LINT falls back to auto-detection. |
| `theme` | Default theme when one isn't provided with `--theme`. Leave blank for no theme. |
| `plugins` | Default plugins for new instances when not provided with `--plugin`. Leave blank for none. |

### `[instance.folders]`

| Key | Description |
|:--|:--|
| `root_folder` | Base directory for new instances. |
| `folder_name` | Instance folder name template. Supports `{game}` and `{launcher}` placeholders. |

{: .tip }
> A `root_folder` of `~/Games` and a `folder_name` of `mo2-{game}` installs a Fallout 4 instance at `~/Games/mo2-fallout4`.

## The instance state file: `state.json`

Located at `~/.config/mo2-lint/state.json`. MO2-LINT tracks every managed instance here, and reads/writes it automatically during `install`, `uninstall`, `list`, `pin`, `unpin`, and `update`.

{: .danger }
> **Do not edit this file manually.** Doing so may cause inconsistencies or errors when managing instances. If it becomes corrupted, see [Instance & Data Issues](../troubleshooting/instance-and-data-issues.html).
