---
title: Skyrim Anniversary Edition
---

Skyrim Anniversary Edition (AE) is set up differently depending on whether you own it on Steam or through Heroic, because GOG and Epic list Skyrim AE as an entirely separate game.

- If you are using the Steam version, use the `skyrim_se` game slug to set up an instance.
- If you are using the Heroic version, you must use the `skyrim_ae` game slug to set up an instance.

:::danger
The `skyrim_ae` game slug is **only** for the Heroic version of Skyrim AE. If you use it for the Steam version, the installer **will** fail to set up the instance correctly. Use `skyrim_se` for the Steam version.
:::
