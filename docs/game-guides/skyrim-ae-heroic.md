# Skyrim Anniversary Edition on Heroic Games Launcher

Skyrim Anniversary Edition (AE) has different installation methods depending on install via Steam or a Heroic platform, as the GOG and Epic versions of Skyrim AE receive updates less frequently than the Steam version.

If you are using the Steam version, you can use the `skyrim_se` game identifier to set up an instance. If you are using the Heroic version, you must use the `skyrim_ae` game identifier to set up an instance.

{: .warning }
> The `skyrim_ae` game identifier is **only** for the Heroic version of Skyrim AE. If you use it for the Steam version, the installer **will** fail to set up the instance correctly. Use `skyrim_se` for the Steam version.
