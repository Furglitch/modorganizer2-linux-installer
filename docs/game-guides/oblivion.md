# Oblivion

Oblivion's script extender has some quirks when used with Mod Organizer 2 on Linux.

## Script Extender

Some xOBSE plugins may require further manual setup beyond the standard installation. [#63](https://github.com/furglitch/modorganizer2-linux-installer/issues/63) has more information on this.
