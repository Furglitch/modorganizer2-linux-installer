# Game Guides

Some games need additional setup or have specific quirks when used with MO2-LINT. Check here before running `install` for your game.

{: .note }
> These guides are community-contributed and may not cover every scenario. If you hit something not covered here, [open an issue](https://github.com/furglitch/modorganizer2-linux-installer/issues) on GitHub.
