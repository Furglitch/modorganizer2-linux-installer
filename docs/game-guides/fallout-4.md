# Fallout 4

Fallout 4's script extender and ENB have some quirks when used with Mod Organizer 2 on Linux.

## Script Extender

Some F4SE plugins may not work properly under Proton/Wine. [#32](https://github.com/furglitch/modorganizer2-linux-installer/issues/32) has more information on this.

## ENB

Version 0.393 and below may need 'EnablePostPassShader' to be disabled in order to work properly. [#95](https://github.com/furglitch/modorganizer2-linux-installer/issues/95) has more information on this.
