# Getting Started

This section walks through everything needed to go from a fresh system to a working Mod Organizer 2 instance, in order:

1. [Requirements](./requirements.html) - what your system needs before you begin.
2. [Installing MO2-LINT](./installing.html) - downloading and running the binary.
3. [Setting up Proton](./proton-setup.html) - required for MO2-LINT to function.
4. [First Launch](./first-launch.html) - verifying everything worked.

{: .tip }
> Already have MO2-LINT installed and just need command reference? Skip ahead to the [CLI Guide](../guide/).
>
> Coming from a pre-7.0.0 install with an existing v6 instance? See [Uninstalling Legacy (v6) Instances](../uninstalling-legacy.html) instead. v6 instances are not compatible with v7 and need a one-time migration.
