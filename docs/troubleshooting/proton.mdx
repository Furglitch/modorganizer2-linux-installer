## Wrong Proton Version

MO2-LINT is tested against Proton 11.0. See [Proton Versions](../resources/proton.mdx) for other supported versions, and [Proton Setup](../getting-started/3-proton.mdx) for how to select a version on Steam and Heroic.

## Prefix Not Initialized

Launch the game at least once through Steam/Heroic **before** creating an instance, so the launcher can set up the Proton prefix with its default dependencies.
