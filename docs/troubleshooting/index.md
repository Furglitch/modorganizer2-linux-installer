# Troubleshooting

Pick the page that matches your symptom:

| Symptom | Page |
|:--|:--|
| Errors during `install` (download, game not found, permissions) | [Installation Issues](./installation-issues.html) |
| MO2 won't launch, crashes, or misbehaves through Steam/Heroic | [Launch & Proton Issues](./launch-issues.html) |
| Nexus Mods "Mod Manager Download" doesn't work | [NXM Handler Issues](./nxm-handler-issues.html) |
| Missing instances, pinned versions, save data, log files | [Instance & Data Issues](./instance-and-data-issues.html) |

Still stuck? See [Log Files & Reporting Issues](./instance-and-data-issues.html#log-files) for what to include in a bug report.
