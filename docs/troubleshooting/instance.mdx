## Instance Not Found

If `mo2-lint list` doesn't show your instance, the state file may be out of date. It's located at `~/.config/mo2-lint/state.json`.

:::danger
Do not manually edit this file. If it becomes outdated or corrupted, you may need to reinstall MO2-LINT instances.
:::

## Cannot Update a Pinned Instance

Pinned instances won't update their MO2 version. Unpin first:

```bash
mo2-lint unpin /path/to/instance
```

Alternatively, providing a custom build with `--mo2-archive` updates a pinned instance without unpinning it. See [`update`](../cli-guide/command-reference.mdx#update).

See the [Command Reference](../cli-guide/command-reference.mdx#pin-and-unpin) for more on pinning.

## Refreshing a Prefix

A Wine/Proton prefix contains the filesystem of the simulated Windows environment that Wine/Proton uses to run your game. Depending on changes made to the prefix, it may be beneficial to reset the prefix.

Prefix folders can be found in the below locations. If you installed a game in a secondary location (second drive, etc.), the game's prefix will be near that same location.
- **Steam**: `<Steam Library location>/steamapps/compatdata/<Game ID>/pfx`
- **Heroic (GOG / Epic)**: `<Heroic Library location>/prefixes/<Game Name>/`

:::danger
If you have save data, it *will* be deleted along with your prefix. See **[Preserving Save Data Across a Prefix Reset](#preserving-save-data-across-a-prefix-reset)** below *before* proceeding with resetting your game's prefix.
:::

After preserving saves where necessary, delete the prefix folder and launch the game once to allow standard setup to process. For games with a launcher, allowing the launcher to appear should be enough. For games without a launcher, wait until the main menu appears before closing.

### Preserving Save Data Across a Prefix Reset

Save data lives inside the prefix under the `users` folder.

**To preserve your saves:**

1. Copy the `users` folder somewhere safe before deleting the prefix:
   ```bash
   mkdir -p ~/mo2-lint-backup
   cp -r </path/to/prefix>/drive_c/users ~/mo2-lint-backup/users
   ```
2. Delete the old prefix and launch the game once to generate a fresh one, then exit.
3. Restore your saves:
   ```bash
   cp -r ~/mo2-lint-backup/users/. </path/to/prefix>/drive_c/users/
   ```

:::note
Overwriting the whole `users` folder should be safe for save data, but some per-user configuration inside the prefix (e.g. registry hives under `users/<name>/`, altered game configuration files) may carry over stale settings from the old prefix.
:::
