## Ensure Nexus Downloads Are Enabled in Mod Organizer

Open Mod Organizer's settings by clicking the wrench (🛠️) icon above your modlist, then open the **Nexus** tab.

### Under Nexus Connection

If the text box does not say `Connected.`, click **Connect to Nexus** and authorize in your browser.

:::tip
If the **Connect to Nexus** button is unavailable (grayed out), click **Enter API Key Manually**, then **Open Browser**. Log in to Nexus Mods, then scroll until you see **Mod Organizer 2** (not **Mod Organizer 2 Linux Installer**). Click **Request API Key**, then copy the key (the two-squares icon) and paste it into the **Enter API key here** box in Mod Organizer. Click **OK** to save.
:::

Once connected, you should see `Connected.` in the **Nexus Connection** section.

### Under Options

Click **Associate with "Download with manager" links**. There is no visual change, so you may want to click it again to make sure it registered.

:::warning
Downloads still will not work at this point. When you click **OK** to save settings, Mod Organizer will prompt you to restart. If you don't restart, the changes won't take effect.
:::

## Premium-Only Downloads

If you see a message like:

```
Aborting download: Either you clicked on a premium-only link and your account is not premium, or the download link was generated by a different account than the one stored in Mod Organizer.
```

Your Nexus Mods account isn't Premium, or your Premium status isn't registering with Nexus. This isn't a fault of MO2-LINT or the NXM handler; contact Nexus Mods support.

## Check Handler Files Exist

Confirm these exist and aren't empty:

- `~/.local/share/mo2-lint/nxm-handler`
- `~/.local/share/applications/mo2lint_nxm-handler.desktop`

If they're missing, run `mo2-lint update <directory>` on any instance to reinstall the handler.

## Verify Handler Registration

```bash
xdg-mime query default x-scheme-handler/nxm
```

This should return `mo2lint_nxm-handler.desktop`. If not, register it manually:

```bash
xdg-mime default ~/.local/share/applications/mo2lint_nxm-handler.desktop x-scheme-handler/nxm
```

## Check Browser Settings

Some browsers have their own protocol handler settings. Make sure yours is configured to use the system default for `nxm` links.

## `qtpaths` Error

:::note
Often encountered on Fedora 41+ and Manjaro with KDE 6.
:::

If logs show `/usr/bin/xdg-mime: line 885: qtpaths: command not found`, create a symlink:

```bash
sudo ln -s /usr/bin/qtpaths6 /usr/bin/qtpaths
```
